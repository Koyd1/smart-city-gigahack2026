# Program sportiv „EXCLUSIV HANDBAL”

###### Invităm tinerii să descopere beneficiile handbalului. Handbalul este un sport frumos care te ajută să îți menții corpul într-o formă sănătoasă.
Îmbunătățește agilitatea, flexibilitatea și sistemul cardiovascular al organismului. Este un joc rapid ce presupune forță, viteză și agilitate.
